# Bubble Grimoire（バブル・グリモワール）

魔導書で射撃魔法を使う魔法使いの女性が、シャボン玉を撃つスライムと戦う3Dアクション。
Godot 4.3 製。スマホのブラウザ（Web版）で遊べます。

## 遊び方
- 左半分をドラッグ：移動（仮想スティック）
- 右下の MAGIC ボタン：射撃魔法（一番近いスライムに自動で狙いが付きます）
- PC：矢印キーで移動 / Space で魔法

## ゲームのルール
- スライムは予測線（ピンクの線）を出してから、閉じ込めシャボン玉を撃ってきます
- 1回目に当たると **魔導書だけ** が閉じ込められ、魔法が弱く遅くなります（8秒）
- 魔導書が閉じ込められた状態でもう一度当たると **全身** が閉じ込められ、
  動けずふわふわ漂います（HP -1）。ボタン連打で早く脱出できます
- 魔法は MP を消費します。連射するとすぐ尽きるので注意
- 魔法でシャボン玉を割ることもできます
- 全3ウェーブを倒せばクリア

## ローカルで動かす
1. Godot 4.3 以降をインストール
2. Godot の「インポート」でこのフォルダの `project.godot` を選ぶ
3. ▶（F5）で実行

## GitHub で公開する（ブラウザで遊べるようにする）
1. GitHub で新しいリポジトリを作り、このフォルダの中身を `main` ブランチに push
2. リポジトリの **Settings → Pages → Build and deployment → Source** を **GitHub Actions** にする
3. push すると `.github/workflows/deploy.yml` が自動でWebビルドして公開します
4. 公開URL: `https://<ユーザー名>.github.io/<リポジトリ名>/`
   （スマホでこのURLを開けば遊べます）

## ファイル構成
- `scripts/main.gd` … ステージ・ウェーブ進行・カメラ
- `scripts/player.gd` … 主人公（移動・魔法・閉じ込められ状態・モーション）
- `scripts/slime.gd` … スライム（予備動作・予測線・シャボン玉発射）
- `scripts/bubble_shot.gd` / `magic_bolt.gd` … 弾
- `scripts/hud.gd` … タッチ操作とHP/MP表示
- `scripts/fx.gd` … 共通ヘルパー

## 次にやれること
- キャラクターは図形で作った仮の見た目です。Blender等で作った `.glb` を
  プロジェクトに入れ、`player.gd` の `_build_model()` を差し替えると本格的な3Dモデルにできます
- 画面の文字は英語です（Web版の標準フォントに日本語が含まれないため）。
  日本語を出したい場合は日本語フォント（例: Noto Sans JP）を同梱してテーマに設定してください
